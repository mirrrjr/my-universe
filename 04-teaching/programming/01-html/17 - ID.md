### ID'siz qanday qilib malum elementga stil beramiz?

> [!NOTE] Inline style
> Biz o'zgartirmoqchi bo'lgan elementimizga inline style orqali stil berishimiz mumkin, lekin bu amaliyotda tavsiya etilmaydi.

```html
<!doctype html>
<html lang="en">
  <head>
    <title>ID'siz</title>
    <style>
      p {
        color: red;
      }
    </style>
  </head>
  <body>
    <h1>ID'ni amalda ko'ramiz</h1>
    <p>
      Lorem ipsum dolor sit, amet consectetur adipisicing elit. Labore, veniam
      consectetur commodi nam ad omnis a necessitatibus neque eligendi quasi.
    </p>
    <p style="color:green">
      Lorem ipsum dolor sit amet consectetur adipisicing elit. Numquam quis odio
      asperiores. Itaque, eaque distinctio.
    </p>
    <p>
      Lorem ipsum dolor sit amet consectetur, adipisicing elit. Excepturi nulla
      enim mollitia possimus fugit doloribus velit molestiae officiis incidunt,
      inventore eos ut accusantium minus beatae natus rem nam expedita quod.
    </p>
  </body>
</html>
```

## ID orqali bu muammo qanday yechiladi?

```html
<!doctype html>
<html lang="en">
  <head>
    <title>ID'siz</title>
    <style>
      p {
        color: red;
      }

      #ikkinchi {
	    color: green;
      }
    </style>
  </head>
  <body>
    <h1>ID'ni amalda ko'ramiz</h1>
    <p>
      Lorem ipsum dolor sit, amet consectetur adipisicing elit. Labore, veniam
      consectetur commodi nam ad omnis a necessitatibus neque eligendi quasi.

      asperiores. Itaque, eaque distinctio.

    </p>

</html>
```
