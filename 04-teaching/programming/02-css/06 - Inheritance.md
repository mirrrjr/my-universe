## Reaja
- Inheritance (meros olish)

> [!NOTE] Eslab qoling
> Inheritance (meros olish) - agar element o'zining stiliga ega bo'lmasa, u shu stilni ota elementdan meros qilib oladi.

```html
<style>
div {
	color: red;
}

p {
	color: blue;
}
</style>

================================
<div>
	<h1>Heading 1</h1>
	<p>Paragraf</p>
<div>
```
