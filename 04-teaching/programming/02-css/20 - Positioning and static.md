- Positing (Joylashuv)

> HTML da elementlar har doim chapdan o'nga, tepadan pastga qarab joylashadi

```html
<style>
	.box {
		background-color: red;
		height: 200px;
	}
	
	.link {
		background-color: blue;
		color: white;
	}
</style>


<div class="box">Box 1</div>
<div class="box">Box 2</div>

<a href="#" class="link">Havola 1</a>
<a href="#" class="link">Havola 2</a>
```

>[!NOTE] Eslab qoling
>HTML da har bir elemntning 4 ta xossalari bor: **top**, **bottom**, **left** va **right**. Ular elementning qanday joylashganini aniqlab beradi.

> **Position** - elementni joylashish turini aniqlab berish uchun ishlatiladigan xossa

Qiymatlari:
- static - HTML da har bir element boshida shu qiymatga ega bo'ladi
- relative
- fixed
- absolute
- sticky
