>Foiz o'lchov birligi **position** xossasining qiymatiga qarb o'zgaradi. Yani foiz o'lchov birligi positon'ning bir qiymati uchun boshqacha,ikkinchi qiymati uchun esa umuman boshqa natijani beradi.

## position: fixed

>**Position** xossais **fixed** qiymatiga ega bo'lgan payti, biz ko'rsatgan foiz qiymatimiz viewport'ga nisbatan o'lchamga ega bo'ladi.

```html
<style>
	.fixed-box {
		position: fixed;
		width: 50%;
		height: 200px;
		background-color: red;
	}
</style>


<div class="fixed-box"></div>
```

## position: absolute

>**Position** xossasi **absolute** qiymatiga ega bo'lgan payti biz ko'rsatgan foiz qiymatimiz eng yaqin **positioned** ajdodning content va padding qiymatlarini yig'indisiga nisbatan o'lchamga ega bo'ladi.


## position: static/relative

>**Position** xossasi **static** yoki **relative** qiymatiga ega bo'lgan payti, biz ko'rsatgan foiz qiymatimiz eng yaqin block turdagi avlodining content qiymatiga nisbatan o'lchamga ega bo'ladi.
